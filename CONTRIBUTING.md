
# 🤝 Contributing to SmartPocket

Thank you for your interest in contributing to **SmartPocket**! We welcome contributions from developers, designers, testers, writers, and financial literacy advocates.

---

## 📦 How to Contribute

### 1. Fork & Clone
- Fork this repository
- Clone your fork:
  ```bash
  git clone https://github.com/your-username/smartpocket.git
  ```

### 2. Create a Branch
Use a descriptive name for your branch:
```bash
git checkout -b feature/add-budget-tracking
```

### 3. Make Your Changes
- Follow the existing code style and structure
- Write clear, meaningful commit messages
- Include comments where necessary

### 4. Test Your Changes
- Make sure the app builds and runs without issues
- Check for any regressions or UI bugs

### 5. Submit a Pull Request
Push to your fork and open a pull request with a clear description.

## 🛠️ Development Setup

1. Install [Flutter](https://flutter.dev/docs/get-started/install)
2. Run `flutter pub get` to install dependencies
3. Use `flutter run` to start the app on a device/emulator
